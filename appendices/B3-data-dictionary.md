# Appendix B3 — Data Dictionary (flat column index)

> **Deliverable L (part).** Every table and every column of the 13-table schema in one searchable list.
>
> This appendix is the **index**; [`../docs/06-database-design.md`](../docs/06-database-design.md) §6.7
> is the **explanation**. Chapter 6 groups the columns by table and says what each one means in plain
> words, with an example value. This file flattens the same 97 columns into one table, sorted by table
> and ordinal, with the key role and the exact constraint beside each — so that when you hit
> `violates check constraint "match_cards_check1"` at 2 a.m. on task day you can find the column in one
> `Ctrl-F` instead of reading a chapter.
>
> Source of truth is [`B-database-schema.sql`](B-database-schema.sql). If this file and the SQL
> disagree, the SQL is right and this file is a bug.

**Tier: `[P1]`,** except the four `match_rules` extension columns, which are `[P2]` and default to off.

**Legend.** `PK` primary key · `FK` foreign key · `UK` unique · `CPK` part of a composite foreign key ·
`gen` generated by the database · `—` no default.

### 2. `maps` — 6 columns

> **Rule, not a constraint:** a map used by a match is never edited. Insert a new row instead (D-50).
> The database cannot enforce this; §6.3 of chapter 6 explains why that is the design's honest cost.

### 3. `continents` — 6 columns

|---|---|---|---|---|---|---|
| 1 | `continent_id` | `integer` | PK | No | gen | |

| 3 | `code` | `text` | UK | No | — | `UNIQUE (map_id, code)`. `NA`, `SA`, `EU`, `AF`, `AS`, `AU` |

Also `UNIQUE (map_id, continent_id)` — present only so the composite FK from `territories` can exist.

### 4. `territories` — 9 columns

| # | Column | Type | Key | Null | Default | Constraint / note |
|---|---|---|---|---|---|---|
| 1 | `territory_id` | `integer` | PK | No | gen | |

| 3 | `continent_id` | `integer` | CPK | No | — | → `continents(map_id, continent_id)`. Forces the continent onto the same map |
| 4 | `key` | `text` | UK | No | — | `UNIQUE (map_id, key)`. Matches the JSON map, e.g. `northern_europe` |
| 5 | `name` | `text` | | No | — | |

| 7 | `card_symbol` | `text` | FK | No | — | → `card_symbols`. **CK-18:** `CHECK (<> 'Wild')` |
| 8 | `label_x` | `integer` | | No | — | Board coordinate for the name and army badge |
| 9 | `label_y` | `integer` | | No | — | |

Also `UNIQUE (map_id, territory_id)` — for the composite FKs from the two edge tables.

> **No capability column (D-10).** `profile(t) = {Infantry} ∪ ({NavalForce} if is_coastal) ∪ {card_symbol}`,
> computed on every call. Caching it is trap 3 of the safety checklist.

### 5. `territory_adjacency` — 4 columns

| # | Column | Type | Key | Null | Default | Constraint / note |
|---|---|---|---|---|---|---|
| 1 | `map_id` | `integer` | CPK | No | — | Part of both composite FKs |
| 2 | `territory_a` | `integer` | PK, CPK | No | — | → `territories(map_id, territory_id)`. Always the **smaller** id |
| 3 | `territory_b` | `integer` | PK, CPK | No | — | → `territories(map_id, territory_id)` |
| 4 | `crosses_water` | `boolean` | | No | `false` | **Render hint only.** Draw dashed. No game meaning (D-04) |

**CK-19:** `CHECK (territory_a < territory_b)` — this is what makes "each border stored once" true. 83
borders, 83 rows. 10 of them have `crosses_water = true`.

### 6. `sea_routes` — 4 columns `[P2]`

| # | Column | Type | Key | Null | Default | Constraint / note |
|---|---|---|---|---|---|---|
| 1 | `sea_route_id` | `integer` | PK | No | gen | |
| 2 | `map_id` | `integer` | CPK | No | — | |
| 3 | `territory_a` | `integer` | UK, CPK | No | — | `UNIQUE (territory_a, territory_b)`. Must be coastal |
| 4 | `territory_b` | `integer` | UK, CPK | No | — | Must be coastal |

**CK-20:** `CHECK (territory_a < territory_b)`.

Two rules the database cannot express, checked by `tools/verify_db.sql` V1–V2 and by
`tools/generate_map_seed.py` before it emits a row: **both ends coastal**, and **not already a land
border**. Ships empty (D-37); a proposed list of eight is in
[`C-map-specification.md`](C-map-specification.md).

| 3 | `created_by` | `uuid` | FK | No | — | → `users`. The host |

| 7 | `current_seat_no` | `smallint` | CPK | **Yes** | — | → `seats(match_id, seat_no)`, added by `ALTER` after `seats` exists. Null in the lobby |
| 8 | `round_no` | `integer` | | No | `0` | **CK-06:** `>= 0` |

**Columns that used to be here and are not:** `effective_map` (D-50 — reach the map through `map_id`),

and the turn timer (O-05, retired by D-65).

### 9. `match_rules` — 12 columns · exactly one row per match

| # | Column | Type | Key | Null | Default | Constraint / note |
|---|---|---|---|---|---|---|
| 1 | `match_id` | `uuid` | PK, FK | No | — | → `matches` `ON DELETE CASCADE`. PK **is** the FK, which is what makes it 1:1 |
| 2 | `dice_sides` | `smallint` | | No | `6` | **CK-21:** `BETWEEN 2 AND 20` (D-29). Not shown in the UI (D-39) |
| 3 | `attack_range` | `smallint` | | No | `1` | **CK-22:** `BETWEEN 1 AND 10` (D-30). `1` **is** adjacency. Not shown in the UI |
| 4 | `defender_wins_ties` | `boolean` | | No | `true` | DR-07. The single highest-risk flag in the whole project |
| 5 | `territory_allocation` | `text` | | No | `'claim'` | `CHECK IN ('claim','random')` |
| 6 | `fortify_mode` | `text` | | No | `'single_pair'` | `CHECK IN ('single_pair','one_step_all','connected_path')` (D-16) |
| 7 | `wild_cards` | `smallint` | | No | `2` | `CHECK (>= 0)` |
| 8 | `round_cap` | `integer` | | No | `100` | `CHECK (> 0)` |
| 9 | `air_force_enabled` | `boolean` | | No | `false` | `[P2]` Off by default (D-54) |
| 10 | `air_max_range` | `smallint` | | No | `5` | `[P2]` **CK-23:** `BETWEEN 1 AND 10` (D-11) |
| 11 | `air_attacks_per_turn` | `smallint` | | No | `1` | `[P2]` `CHECK (>= 1)` (assumption AIR-1) |
| 12 | `naval_force_enabled` | `boolean` | | No | `false` | `[P2]` Off by default (D-54) |

> **Written once, at match creation; never read live afterwards (D-52).** This is trap 6 of the safety
> checklist as a schema. A live read of `dice_sides` keeps `rng_position` in perfect agreement with the
> log while changing every die face — the determinism suite stays green and the replay has diverged.
> **TC-PER-07** asserts the *source* of the value, not the value.

At every default this row describes exactly classic RISK.

### 10. `seats` — 10 columns

| # | Column | Type | Key | Null | Default | Constraint / note |
|---|---|---|---|---|---|---|
| 1 | `match_id` | `uuid` | PK, FK | No | — | → `matches` cascade |
| 2 | `seat_no` | `smallint` | PK | No | — | **CK-08:** `BETWEEN 0 AND 5`. Also the turn order |
| 3 | `kind` | `text` | | No | — | **CK-09:** `Human`, `Ai`, `Neutral` (D-55 — three kinds, not four) |
| 4 | `user_id` | `uuid` | FK | **Yes** | — | → `users`. `ux_seats_one_seat_per_user` on `(match_id, user_id)` |
| 5 | `ai_agent` | `text` | | **Yes** | — | **CK-12:** `PassiveBot`, `ChaoticBot`, `AggressiveBot`, `MarsBot` (D-56) |
| 6 | `colour` | `text` | | No | — | Hex. The six seat colours of `design/01-design-system.md` |
| 7 | `status` | `text` | | No | `'active'` | **CK-11:** `active`, `eliminated`, `left` |
| 8 | `eliminated_by_seat` | `smallint` | CPK | **Yes** | — | → `seats(match_id, seat_no)`. **CK-13:** `<> seat_no`. Drives card transfer (FR-38) |
| 9 | `eliminated_round` | `integer` | | **Yes** | — | `CHECK`: null unless `status = 'eliminated'` |
| 10 | `final_rank` | `smallint` | | **Yes** | — | `CHECK (BETWEEN 1 AND 6)` |

**CK-10**, the three-way rule, is the one worth reading aloud:

```sql
CHECK ( (kind = 'Human'   AND user_id IS NOT NULL AND ai_agent IS NULL)
     OR (kind = 'Ai'      AND user_id IS NULL     AND ai_agent IS NOT NULL)
     OR (kind = 'Neutral' AND user_id IS NULL     AND ai_agent IS NULL) )
```

A human seat without an account, or an AI seat without a bot, is **unrepresentable** rather than
merely discouraged.

`Neutral` appears in 2-player matches only (D-07, D-62); it never acts and the server skips its turn.

### 11. `match_territories` — 4 columns

| # | Column | Type | Key | Null | Default | Constraint / note |
|---|---|---|---|---|---|---|
| 1 | `match_id` | `uuid` | PK, FK | No | — | → `matches` cascade |
| 2 | `territory_id` | `integer` | PK, FK | No | — | → `territories`. The board itself is never copied here |
| 3 | `owner_seat_no` | `smallint` | CPK | No | — | → `seats(match_id, owner_seat_no)` |
| 4 | `armies` | `integer` | | No | — | **CK-14:** `>= 1` — a territory is never empty (DR-04) |

Index `ix_match_territories_owner (match_id, owner_seat_no)` — used every draft phase to count
territories per seat. 42 rows per match once the claim phase is over. Replaces `territory_state`.

### 12. `match_cards` — 6 columns

| # | Column | Type | Key | Null | Default | Constraint / note |
|---|---|---|---|---|---|---|
| 1 | `match_id` | `uuid` | PK, FK | No | — | → `matches` cascade |
| 2 | `card_no` | `smallint` | PK | No | — | `CHECK (>= 1)`. 1…44 on the classic board |
| 3 | `territory_id` | `integer` | FK, UK | **Yes** | — | → `territories`. `UNIQUE (match_id, territory_id)`. **Null = Wild card** |
| 4 | `location` | `text` | | No | — | **CK-15:** `deck`, `hand`, `discard` |
| 5 | `holder_seat_no` | `smallint` | CPK | **Yes** | — | → `seats`. **CK-16:** non-null **iff** `location = 'hand'` |
| 6 | `deck_order` | `integer` | | **Yes** | — | **CK-17:** non-null **iff** `location = 'deck'`. Set by the match seed, so the shuffle replays |

Index `ix_match_cards_hand` is partial — `WHERE location = 'hand'` — because a hand is the only thing
ever looked up by holder.

**No `symbol` column (D-51).** The symbol is the territory's `card_symbol`, or `Wild` when
`territory_id` is null. The deck keeps all six symbols even while the extensions are off (D-63).

## Where to look when something breaks

| Symptom | Likely column | Likely constraint |
|---|---|---|
| `violates check constraint` on an attack | `match_territories.armies` | CK-14 — something tried to leave a territory empty |
| A border insert fails on re-seeding | `territory_adjacency.territory_a/_b` | CK-19 — ids not in ascending order; use `LEAST`/`GREATEST` |
| A seat insert fails | `seats.kind` / `user_id` / `ai_agent` | CK-10 — the three-way rule |
| "Room code already in use" but the game ended | `matches.status` | `ux_matches_active_room_code` is partial; set `status` to `finished` or `abandoned` |
| A card appears in nobody's hand | `match_cards.holder_seat_no` | CK-16 — biconditional |
| Dice look wrong after a resume | `match_rules.dice_sides` | **Not a constraint.** Trap 6 — the engine read `rules.json` live. TC-PER-07 |
| Two phones overwrite each other | `matches.version` | Not a constraint — the `WHERE version = @expected` clause is missing |
| A naval action has nowhere to go | `sea_routes` | Table is empty by design (D-37); add a route before enabling Naval Force |
